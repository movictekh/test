# Pixel-Match Review Checklist

For every screen verify:

## Structure

- same title and breadcrumb;
- same top actions;
- same section order;
- same cards, tables, dialogs, and workflow.

## Dimensions

- shell and sidebar widths;
- header and topbar heights;
- content padding;
- card padding;
- grids and gaps;
- controls and rows.

## Visual language

- colours;
- typography;
- borders;
- radii;
- shadows;
- pills;
- icons;
- active, hover, selected, and disabled states.

## States

- loading;
- data;
- empty;
- error;
- validation;
- unauthorized;
- forbidden;
- success;
- pending mutation.

## Behaviour

- buttons open the same workflows;
- filters affect the correct records;
- forms contain the prototype fields;
- confirmations exist where expected;
- cross-screen links work;
- mock mutations visibly update the product.

## Responsive and accessibility

Review desktop, laptop, tablet, mobile, collapsed sidebar, keyboard use, focus, labels, semantic tables, dialog focus, and status meaning beyond colour.

## Review evidence

Store a prototype screenshot, implementation screenshot, known differences, reason for each accepted difference, and reviewer sign-off.
